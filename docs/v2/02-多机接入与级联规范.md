# 多机接入与级联规范（基线草案）

> 适用于站点边缘 → 区域中心 → 省中心的三级级联，以及重点站星型直连。
> 主题、桥接、鉴权、补传为本方案的强约束，实现与验收均以此为准。

---

## 1. 拓扑与角色

| 层级 | 角色 | 组件 | 本地保留 |
|---|---|---|---|
| L0 | 站点边缘 | Rust Agent + NanoMQ/Mosquitto | 1s 原始值 7~30 天 |
| L1 | 区域中心（地市） | Broker 集群 + 级联服务 + TSDB | 1min 明细 30~90 天 |
| L2 | 省中心 | Broker 集群 + 业务平台 + TSDB 主库 | 1min 聚合 + 事件，3 年 |
| L3 | 灾备/上级平台 | 同构，单向复制 | 按需 |

星型直连：重点站跳过 L1，直接连 L2；**复用同一套主题与 ACL，只少一跳**。

---

## 2. MQTT 主题（5 段式，方向分离）

```
# 上行（数据面）
d/{prov}/{region}/{station}/_batch              # 打包遥测，QoS1，非 retain
d/{prov}/{region}/{station}/_agg/{period}       # 聚合值（1min/5min/1h）
d/{prov}/{region}/{station}/{point}             # 单点实时（调试/重点站）
s/{prov}/{region}/{station}/state               # 在线状态，retain + LWT
e/{prov}/{region}/{station}/{severity}/{code}   # 告警事件，QoS1

# 下行（控制面）
c/{prov}/{region}/{station}/{cmd}               # 单站命令，带 cmdId
c/{prov}/broadcast/{cmd}                        # 省级广播（订阅端 $share）
cfg/{prov}/{region}/{station}                   # 配置版本通告，retain

# 回执（MQTT5 Request/Response）
r/{prov}/{region}/{station}/{cmdId}
```

约定：
- 段位固定、编码用 ASCII（避免中文与通配歧义）；
- `d/` 与 `c/` 是两棵独立命名树，**任何 Broker 对之间不做双向同主题桥**；
- MQTT5 User Property 携带 `traceId`、`hop`、`level`、`operator`、`schemaVer`；
- `Message Expiry Interval` 控制数据时效，防止陈旧数据倒灌；
- `$share` 只能用于订阅端。

## 3. 报文

### 3.1 遥测批量（`_batch`）

```json
{
  "msgId": "01J...ULID",
  "station": "S-350102-001",
  "seq": 10241,
  "ts": 1763200000000,
  "schemaVer": 1,
  "readings": [
    { "device": "D-01", "point": "temp", "value": 23.5, "quality": "good", "ts": 1763199998000 }
  ]
}
```

- 单条 ≤256 KB，超限分片并共享 `msgId`；
- QoS1；站端持久队列按 `seq` 单调递增；
- 质量码：`good / bad / stale / comm_error / maintenance`。

### 3.2 状态（`state`）

`{"online":true,"fw":"1.2.3","cfgVer":12,"ts":...}`，retain；LWT 置 `offline`。

### 3.3 命令与回执

```json
// c/.../{cmd}
{ "cmdId":"...", "type":"relay.write", "params":{"channel":3,"value":1}, "expireAt":1763200060000 }
// r/.../{cmdId}
{ "cmdId":"...", "ok":true, "code":"0", "message":"", "ts":... }
```

命令必须带 `cmdId`、过期时间、操作者；服务端落库并审计；超时进死信。

## 4. 桥接规则

| 跳 | 上行 | 下行 |
|---|---|---|
| L0 → L1 | 订本地 `d/{prov}/{region}/#` → 推上级 | 订上级 `c/{prov}/{region}/#` → 推本地 |
| L1 → L2 | 订本地 `d/{prov}/#` → 推上级 | 订上级 `c/{prov}/#` → 推本地 |
| 星型 → L2 | 本站 `d/.../{station}/#` | `c/.../{station}/#` |

防环 7 条（必须同时生效）：
1. 上下行主题分离；
2. 只桥明确子树，禁止 `#` 双向；
3. MQTT5 `noLocal=1`；
4. Mosquitto `try_private`；
5. 优先 Cluster Linking（自动防环）；
6. 应用层 `hop` 阈值 + `Message Expiry`；
7. 同一对 Broker 只允许一条活跃桥；上行多桥必须下游幂等。

---

## 5. 接入方式

| 模式 | 适用 | 做法 |
|---|---|---|
| M1 MQTT 直连 | 数采网关支持 MQTT | 配 Broker/主题/证书，平台登记站点 |
| M2 Modbus TCP | 网关暴露多个从站 | 平台/Agent 轮询，单元号映射 |
| M3 边缘 Agent | 网关不可改或需私有帧 | 安装 Rust Agent，模板驱动采集 |
| M4 串口直连 | 站点有工控机 | Agent 接 485/232/TTL，或 mbusd/ser2net 转 TCP |
| M5 第三方平台 | 对方提供 API/MQTT | 适配器接入，映射为标准测点 |

## 6. 注册与鉴权

1. 平台创建 `region`/`station`，签发一次性 `stationToken`；
2. 站点首连携带 token + 型号 + 固件版本 + 通道清单，平台登记并下发配置版本；
3. 设备证书：mTLS 一机一证；JWT 短 TTL（含 `prov/region/station` claim）；
4. 级间：bridge 专用账号 + 双向 TLS，仅授权必要前缀；
5. 命令：与数据分离，经命令服务审批/限速/审计，省级仅对 `c/{prov}/#` 有写权。

ACL 示例：设备只能发布 `d/{prov}/{region}/{station}/#`，只能订阅 `c/{prov}/{region}/{station}/#` 与 `cfg/.../{station}`。

---

## 7. 断网自治与续传

- 站端：SQLite 持久队列 + 单调 `seq`；断网继续采集、入库、本地告警；
- 传输：QoS1（不用 QoS2），`session expiry ≥ 最长断网时长`；
- 幂等：业务键 `hash(station,point,ts,seq)`；Redis 布隆 + TSDB upsert；
- 补传：服务端按站做 seq 缺口检测 → 下发补传请求 → 站端回捞；
- 时钟：站端 NTP/北斗；数据带采集时刻 + 接收时刻双时间轴，容忍乱序；
- 背压：上行桥设 inflight/队列上限，满则丢旧保新并告警；
- 限速：恢复后按站点 500 msg/s、全局令牌桶回放，避免雪崩。

---

## 8. 容量与失败处理

| 场景 | 处理 |
|---|---|
| 单站断网 7 天 | 队列按 1min 聚合压缩，恢复后限速补传 |
| 区域中心故障 | 站点直连省中心（DNS/备用地址），或本地保留待恢复 |
| 省中心故障 | 区域中心本地闭环，恢复后补传 |
| 消息重复 | 幂等键去重，重复丢弃并计数 |
| 命令超时 | 死信 + 审计 + 可重试 |
| 时钟漂移 | 偏差 >5s 触发校时，记录事件 |

---

## 9. 监控指标

- 每站：在线率、上报延迟 P95、seq 缺口、队列深度、补传速率；
- 每级：消息速率、桥接积压、丢弃数、命令成功率；
- 平台：入库延迟、查询 P95、TSDB 写入失败率。
