# 前后端分离与部署（基线草案）

> 覆盖：SPA 托管、API 版本化、OpenResty 接入、环境划分、镜像与离线交付。

---

## 1. 部署形态

### 1.1 最小单机（试点/演示）

```
OpenResty :80/:443
  ├─ /            → 静态 SPA
  ├─ /api/v1      → 平台 API（127.0.0.1:8080）
  └─ :8883        → Broker（L4 透传）
PostgreSQL + 时序库 + Broker 同机
```

### 1.2 区域中心

- Broker 集群 3 节点 + 本地时序库 + 级联服务；
- 平台 API 2 副本（无状态）；
- 站点通过 MQTT/TLS 接入，断网本地闭环。

### 1.3 省中心（高可用）

```
              ┌── OpenResty/云 NLB（VIP）
              │
   ┌──────────┼──────────┐
 API-1      API-2      API-3      （无状态，按 CPU 扩缩）
   │          │          │
 PostgreSQL 主/备     时序库 2~3 副本
              │
 Broker 3~5 节点（Cluster Linking 到区域）
```

- API 无状态：会话在 Redis/Token，文件在对象存储；
- 数据库主备 + 定期备份；时序库按时间分区与 TTL；
- 灾备：单向复制到 L3。

## 2. 前后端分离

| 项 | 约定 |
|---|---|
| 构建产物 | `frontend/dist` 静态文件，不进入后端 jar |
| 路由 | `history` 模式；Nginx `try_files $uri $uri/ /index.html` |
| API 前缀 | `/api/v1`，破坏性变更升 `/api/v2` |
| 同域 | 默认同域反代，无 CORS |
| 跨域 | 白名单 + 预检缓存；禁止 `*` 携带凭据 |
| 缓存 | 带 hash 的静态资源长缓存；`index.html` 不缓存 |
| 版本 | 构建注入 `APP_VERSION`、`COMMIT`，页面可查 |
| 灰度 | 前后端独立发布；后端兼容 N-1 前端 |
| 安全头 | CSP、`X-Frame-Options`、`X-Content-Type-Options`、HSTS |

## 3. OpenResty 接入

### 3.1 职责边界

| 做 | 不做 |
|---|---|
| L4 TCP/TLS 透传、SNI 分流 | 终止设备 mTLS（证书信息会丢） |
| MQTT over WebSocket 反代 | topic 级限速/鉴权（属 Broker） |
| REST 限流、WAF、灰度 | 业务鉴权 |
| 静态资源与压缩 | 协议路由 |

### 3.2 关键配置原则

```nginx
# MQTT L4 透传（保留客户端证书到 Broker）
stream {
  upstream mqtt { server 10.0.0.11:1883; server 10.0.0.12:1883; }
  server {
    listen 8883 ssl;
    ssl_preread on;
    proxy_pass mqtt;
    proxy_protocol on;
  }
}

# MQTT over WebSocket
location /mqtt {
  proxy_pass http://mqtt_ws;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
  proxy_buffering off;
  proxy_read_timeout 3600s;
}
```

- 限流只对 WS 握手与 REST：`limit_conn`、`limit_req`；
- 大流量 L4 建议 HAProxy/云 NLB，OpenResty 专注 L7。

## 4. 环境与配置

| 环境 | 用途 | 数据 |
|---|---|---|
| dev | 本地开发 | 容器内 MySQL/PG + 模拟器 |
| test | 联调/压测 | 独立库，可重置 |
| staging | 验收演练 | 生产同构，脱敏数据 |
| prod | 生产 | 主备 + 备份 |

配置优先级：环境变量 > 配置文件 > 默认值；密钥用 Secret/环境变量，禁止入库。

## 5. 镜像与交付

| 镜像 | 内容 | 说明 |
|---|---|---|
| `jdrk/web` | SPA + Nginx | 多阶段构建 |
| `jdrk/api` | 平台 API | Go 静态二进制，distroless |
| `jdrk/cascade` | 级联服务 | 同上 |
| `jdrk/agent` | Rust Agent | ARM64/AMD64 交叉编译 |
| 第三方 | Broker/TSDB/PG/Redis | 固定版本，离线镜像包 |

离线交付：
1. `docker save` 全部镜像 + `docker-compose.yml` + `.env.example`；
2. 校验清单（SHA256）与安装脚本；
3. 首次启动初始化管理员，强制改密。

## 6. CI/CD

| 阶段 | 内容 |
|---|---|
| 提交 | lint + 单测 + 构建 |
| 镜像 | 多架构构建（amd64/arm64），打 tag（版本 + commit） |
| 部署 | staging 自动，prod 手动审批 |
| 回滚 | 保留 N-2 镜像与数据库迁移回滚脚本 |
| 迁移 | 数据库变更向前兼容，先加列后删列 |
