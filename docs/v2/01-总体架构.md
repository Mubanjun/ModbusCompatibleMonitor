# v2 总体架构（基线草案）

> 状态：基线草案，随 ADR-001~007 确认后定稿。
> 目标：省级环境监测平台，前后端分离，多级/星型多机接入，设备模板化。

---

## 1. 设计目标

| 维度 | 目标 |
|---|---|
| 规模 | 3000 站 / 30 万测点；省中心入口 3000~5000 msg/s |
| 采样 | 站端 1s 原始值留 7~30 天；省中心 1min 聚合 + 事件 |
| 可用性 | 省中心 99.9%；区域中心断网可自治 7~30 天 |
| 部署 | 公有云 / 私有云 / 纯内网 / 信创 ARM64 同一套镜像 |
| 接入 | 串口、raw TCP、RFC2217、Modbus TCP、MQTT 网关 |
| 扩展 | 新设备=导入模板；新协议=插件，不改平台代码 |

## 3. 组件职责

| 组件 | 职责 | 选型 |
|---|---|---|
| 接入网关 | TLS 透传、SNI 分流、WS、限流、WAF | OpenResty / Nginx |
| 业务 API | 租户、设备、模板、报警、报表、开放接口 | ThingsPanel 改造（Go） |
| 级联服务 | 多级主题桥、配置/命令/补传、跨级鉴权 | 自研（Go） |
| Broker | 设备接入、会话、离线队列、级联 | VerneMQ / EMQX |
| 时序写入 | 批量、幂等、分区、TTL | 应用侧写手 / Rust 旁路 |
| 边缘 Agent | 采集、模板渲染、缓存、续传、本地告警 | Rust |
| 边缘 Broker | 站内汇聚、弱网桥 | NanoMQ / Mosquitto |
| 可观测 | 指标、日志、追踪 | Prometheus + Grafana + Loki |

## 4. 站点/设备模型

```
tenant（可选）
└── region（省/市/县，权限边界）
    └── station（站点，现场一台边缘主机/网关）
        ├── device（设备，模板实例）
        │   └── point（测点：code、单位、量程、缩放、质量码）
        └── channel（可选：串口/总线配置）
reading（station, device, point, ts, value, quality）
alarm_rule / alarm_record / command / template / template_version
```

与 v1 映射：`port → station/channel`，`device` 保留，`channel/biz_sensor → point`，`biz_sensor_reading → reading`。

## 5. 关键接口

| 接口 | 说明 |
|---|---|
| `POST /api/v1/auth/login` | 账号登录，返回 Access/Refresh Token |
| `GET /api/v1/stations` | 站点列表（按 region 权限过滤） |
| `GET /api/v1/devices?stationId=` | 设备列表 |
| `POST /api/v1/templates/import` | 导入设备模板（JSON + 校验和） |
| `POST /api/v1/commands` | 下发命令（校时/继电器/配置），返回 cmdId |
| `GET /api/v1/readings` | 时序查询（降采样、聚合） |
| `GET /api/v1/open/v1/...` | 对外开放接口（独立 Token 与配额） |
| MQTT `d/...`、`c/...` | 见《02-多机接入与级联规范》 |

所有列表接口强制注入 `region`/`tenant` 过滤，禁止只依赖前端。

## 6. 容量与性能目标

| 指标 | 目标 | 说明 |
|---|---|---|
| 站数 | 3000 | 单省上限 |
| 测点 | 30 万 | 每站 50~200 |
| 上行消息 | 3000~5000 msg/s | 按站打包 |
| 入库 | 5 万点/s 峰值 | 批量写 |
| 查询 P95 | 列表 ≤500ms；1 天曲线 ≤1s | 时序索引 |
| 断网自治 | ≥7 天 | 站端队列 |
| 恢复回放 | ≤30 分钟追平 | 限速 + 背压 |

---

## 7. 安全

- 设备：mTLS（一机一证）+ 短 TTL JWT；ACL 按 `region/station` 前缀。
- 用户：JWT + RBAC；敏感操作二次确认与审计。
- 级间：专用账号 + 双向 TLS，最小主题授权。
- 数据：传输 TLS；导出脱敏；备份加密。
- 网关：不在反代终止设备证书；命令必须经命令服务。

## 8. 与 v1 的关系

| v1 能力 | v2 处置 |
|---|---|
| Spring Boot 业务（设备/报警/上报/同步/迁移） | 作为需求参考与迁移输入，不直接复用运行时代码 |
| MySQL 业务库 | 迁移到 PostgreSQL（元数据） |
| SQLite 暂存 | 由站端队列 + 区域 TSDB 替代 |
| Rust TUI + 看门狗 | 看门狗保留，TUI 降级可选 |
| 仁科兼容输出 | 保留为北向适配器（rkmonitor 库） |
| Docker 编译测试 | 保留并扩展为 v2 镜像流水线 |
