# 设备模板规范（基线草案）

> 模板是平台接入新设备的唯一扩展点：**导入模板即可接入，不改平台代码**。
> 本文定义模板文件结构、字段语义、校验规则与版本管理。

---

## 1. 设计原则

1. 一个模板 = 一个可导入的 JSON 文件（可打包为 zip，含图标/说明）；
2. 模板只描述「怎么采、采什么」，不包含站点/设备实例数据；
3. 模板带版本与校验和，可导入、导出、升级、回滚；
4. 内置模板库随平台发布，现场模板可覆盖内置（按版本比较）；
5. 协议差异通过 `protocol` + `transport` + 可选插件表达，禁止为单一设备改平台。

---

## 2. 文件结构

```json
{
  "schema": "jdrk.template/v1",
  "templateId": "modbus-rtu.generic-sensor",
  "version": "1.2.0",
  "meta": {
    "vendor": "示例厂商",
    "model": "RS-XXX",
    "category": "water-quality",
    "docUrl": "https://example.com/manual.pdf",
    "description": "通用 Modbus RTU 水质传感器"
  },
  "transport": {
    "type": "serial",
    "baudRate": 4800,
    "dataBits": 8,
    "parity": "none",
    "stopBits": 1,
    "timeoutMs": 1000,
    "retries": 2
  },
  "protocol": {
    "type": "modbus-rtu",
    "slaveAddr": 1,
    "byteOrder": "big",
    "wordOrder": "big"
  },
  "points": [
    {
      "code": "temp",
      "name": "温度",
      "unit": "℃",
      "dataType": "int16",
      "functionCode": 3,
      "register": 0,
      "scale": 0.1,
      "offset": 0,
      "range": { "min": -20, "max": 80 },
      "decimals": 1,
      "qualityRule": "range"
    }
  ],
  "commands": [
    {
      "code": "setAddr",
      "name": "修改从站地址",
      "functionCode": 6,
      "register": 1,
      "dataType": "uint16"
    }
  ],
  "sampling": {
    "intervalMs": 10000,
    "timeoutMs": 1000,
    "retries": 2,
    "changeReport": { "enabled": true, "deadband": 0.2 }
  },
  "alarmDefaults": [
    { "point": "temp", "op": ">", "value": 40, "level": "warning", "debounceSec": 30 }
  ],
  "checksum": "sha256:..."
}
```

## 3. 字段说明

### 3.1 transport

| type | 必填字段 | 说明 |
|---|---|---|
| `serial` | `baudRate/dataBits/parity/stopBits` | 本机串口 |
| `tcp` | `host/port` | raw TCP 透传 |
| `rfc2217` | `host/port` | RFC2217 串口服务器 |
| `modbus-tcp` | `host/port/unitId` | Modbus TCP |
| `mqtt` | `broker/topic/clientId` | 网关直连 |

### 3.2 protocol

| type | 说明 |
|---|---|
| `modbus-rtu` / `modbus-ascii` / `modbus-tcp` | 标准 Modbus；`register` 支持 `0x` 或十进制 |
| `raw` | 私有帧，需配合 `codec` 插件或脚本 |
| `hj212` | 环保 HJ212-2017（`CN=2011` 等） |
| `dlt645` | 电表 DL/T 645（1997/2007） |
| `mqtt-json` | 网关 JSON 报文，`jsonPath` 映射 |

### 3.3 points

必填：`code`、`name`、`dataType`、`register`（Modbus）或 `jsonPath`（MQTT）。
`dataType`：`int16 | uint16 | int32 | uint32 | float32 | float64 | bool | string`。
`scale/offset`：工程值 = 原始值 × scale + offset。
`qualityRule`：`none | range | stale | bitmask`。

### 3.4 commands

写操作必须显式声明，未声明的一律拒绝；平台侧再叠加权限与审计。

## 4. 三类示例

### 4.1 Modbus RTU 水质传感器

见 §2 示例；`transport=serial`、`protocol=modbus-rtu`。

### 4.2 MQTT 数采网关（网关已汇聚多设备）

```json
{
  "schema": "jdrk.template/v1",
  "templateId": "mqtt.gateway.standard",
  "version": "1.0.0",
  "transport": { "type": "mqtt", "broker": "ssl://gateway:8883", "topic": "d/{prov}/{region}/{station}/_batch" },
  "protocol": {
    "type": "mqtt-json",
    "mapping": {
      "device": "$.deviceId",
      "points": "$.readings[*]",
      "pointCode": "$.point",
      "value": "$.value",
      "ts": "$.ts"
    }
  },
  "points": [
    { "code": "ph", "name": "pH", "unit": "", "dataType": "float32", "jsonPath": "$.readings[?(@.point=='ph')].value" }
  ]
}
```

### 4.3 HJ212 环保协议（站点数采仪直传）

```json
{
  "schema": "jdrk.template/v1",
  "templateId": "hj212.station.standard",
  "version": "1.0.0",
  "transport": { "type": "tcp", "host": "0.0.0.0", "port": 9000, "mode": "server" },
  "protocol": {
    "type": "hj212",
    "version": "2017",
    "authCode": "{{STATION_AUTH}}",
    "commands": ["CN=2011", "CN=2051", "QN=..."]
  },
  "points": [
    { "code": "w01018", "name": "化学需氧量", "unit": "mg/L", "dataType": "float32", "hjCode": "w01018" }
  ]
}
```

## 5. 校验规则

| 规则 | 说明 |
|---|---|
| schema 版本 | 必须为 `jdrk.template/v1` |
| 唯一性 | `templateId + version` 全局唯一 |
| 引用完整 | `points[].code` 唯一；`alarmDefaults[].point` 必须存在 |
| 范围 | `range.min < range.max`；`scale != 0` |
| 安全 | 禁止模板内出现可执行脚本；表达式仅允许白名单函数 |
| 校验和 | 导入时校验 `checksum`，不一致拒绝 |
| 兼容 | 新版本不得删除已有 `code`（只能废弃），保证实例可升级 |

---

## 6. 生命周期

1. **导入**：上传 JSON → 校验 → 预览差异 → 确认入库（草稿/发布）；
2. **发布**：发布后可用于新设备；已实例化的设备按需升级；
3. **升级**：比较版本，提示新增/变更/废弃点位；支持批量升级与回滚；
4. **导出**：导出模板 + 依赖插件清单，便于现场复用；
5. **废弃**：标记 deprecated，保留历史实例可用。

---

## 7. 与旧需求的对应

| v1 需求 | v2 实现 |
|---|---|
| 设备模板/要素驱动 | 本规范 `points` + `scale/offset` |
| 通道数据格式（整数/浮点/字序） | `dataType` + `wordOrder` + `byteOrder` |
| 量程与缩放字典 | `range` + `scale` + `decimals` |
| 自动探测/批量建号 | 模板 + 地址区间批量导入（后续 FR） |
| 新协议扩展 | `protocol.type` + 插件/编解码器 |
